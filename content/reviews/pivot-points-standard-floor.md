# Pivot_Points_Standard_Floor Review

If you've traded Forex or futures, you already know the Floor method: it's the standard pivot calculation used on most broker terminals. The **Pivot_Points_Standard_Floor** indicator simply plots those levels on your chart. But it does more than draw lines—it creates a framework for the trading day.

## What This Indicator Actually Does

It calculates and displays seven horizontal levels based on the previous period's high, low, and close:

- **Pivot Point (PP)** – the mathematical center
- **Three Resistance levels (R1, R2, R3)**
- **Three Support levels (S1, S2, S3)**

It updates automatically at the start of each new period (daily, weekly, monthly). That's it. No predictive signals, no lagging averages. Just clean levels.

## Key Features That Stand Out

- **No repaint.** The levels are fixed for the entire period. Many pivot indicators recalculate mid-period, which undermines their reliability as reference points. This one doesn't.
- **Multi-timeframe support.** You can set it to daily, weekly, or monthly pivots independently of your chart timeframe.
- **Customizable line styles and colors.** Line styles and colors can be adjusted to make the chart easier to read at a glance.
- **Lightweight.** Designed to run without a meaningful performance impact, even across many charts.

## Settings and How to Tune Them

- **Timeframe.** Set the pivot period independently of your chart timeframe. Daily pivots suit intraday trading; weekly pivots give wider ranges for position trading.
- **Line thickness.** Thicker lines are easier to spot on busy charts; thinner lines reduce clutter.
- **Colors.** A common convention is red for resistance (R1–R3), green for support (S1–S3), and a distinct color for the pivot line itself.
- **Extend lines to the right.** Keeps levels visible as price moves forward.
- **Hiding outer levels.** R3 and S3 are the least frequently touched of the seven, so some traders hide them to reduce chart clutter.

## How to Use It: Entry Logic

This isn't a signal generator. It's a framework. A common approach:

**The "Bounce or Break" method:**

1. **Bounce trade:** If price touches S1 or S2 with a bullish candlestick pattern (hammer, engulfing), a trader might go long with a stop loss below that level, targeting the pivot point or R1.
2. **Break trade:** If price closes decisively above R1, a trader might enter long with a target of R2 and a stop loss below R1.
3. **Reversal at extremes:** When price reaches R3 or S3, traders often look for exhaustion patterns. These levels frequently mark the day's boundary.

The self-fulfilling element is real: thousands of traders watch these levels, so reactions at them are common.

## Pros & Cons

**Pros:**
- Dead simple. No learning curve.
- Applies to any market with high, low, and close data (Forex, crypto, stocks, futures).
- Usable for both intraday and swing trading.
- Free and built into TradingView.

**Cons:**
- Not predictive. It only tells you where price *might* react, not *if* it will.
- Can get noisy on volatile days when price slices through multiple levels.
- No volume or momentum confirmation built in—you need to combine it with something else.

## Who It's For

- **Intraday scalpers** who need quick reference levels for entries and exits.
- **Swing traders** using weekly pivots on daily charts.
- **Beginners** who want a clean, no-nonsense support/resistance tool.
- **Not for you** if you want a "buy/sell" signal. This is a tool, not a robot.

## Alternatives Worth Considering

- **Pivot Points Classic** – Very similar, but some versions include the Camarilla calculation.
- **Fibonacci Pivots** – Same concept but with Fibonacci ratios. Better for trending markets.
- **TV Pivot Points** – Includes multiple calculation methods (Woodie, Camarilla, etc.) in one indicator.

If you need momentum confirmation, pair this with **RSI** or **MACD**—for example, a bounce off S1 combined with a MACD cross above zero.

## FAQ

**Does this indicator repaint?**
No. The levels are fixed for the entire period. Once a daily pivot is set, it stays until the next day.

**Can I use it on crypto?**
Yes. It works on any market with high, low, and close data.

**What timeframe should I set it to?**
Daily for intraday, weekly for swing trading. Monthly only if you're position trading.

## Final Verdict

**⭐⭐⭐⭐ (4/5)**

The Pivot_Points_Standard_Floor is a solid, no-BS tool that belongs on most traders' charts. It won't make you money by itself, but it gives you a reliable framework to plan trades. It loses a star for lacking any confirmation logic—you have to bring your own strategy. That said, for a free, institutional-grade pivot indicator, it's a strong pick.

**Should you install it?**
Yes, especially if you trade intraday or swing. Set it, learn the levels, and watch how price respects them. It's not magic—it's math.
