Most Elliott Wave tools are either overpriced or of limited use. This one is genuinely usable.

## What This Indicator Actually Does

It auto-labels Elliott Wave counts (1-2-3-4-5 impulse, A-B-C corrective) directly on the chart. It then overlays Fibonacci retracement and extension levels based on those wave degrees. The Fib math is standard — no secret sauce — but the automation is the time-saver.

The indicator can identify wave 3 extensions and draw extension levels without manual input.

## Key Features That Set It Apart

- **Multi-degree wave labeling**: It attempts to show primary, intermediate, and minor waves simultaneously. On clean trends this is useful; on choppy price action it gets messy.
- **Auto-Fib levels**: Retracements (0.382, 0.5, 0.618, 0.786) and extensions (1.272, 1.618, 2.618) appear automatically after each completed wave.
- **Customizable color coding**: Different colors can be assigned to each wave degree, which helps when counts overlap.
- **Alert system**: Triggers when a wave count completes or a key Fib level is hit, including wave 3 completion.

## Settings and How to Tune Them

Out of the box, the indicator tends to be aggressive with wave labeling. The following adjustments are worth considering:

- **Wave Degree Sensitivity**: Raising this reduces false counts on minor pullbacks.
- **Minimum Wave Length**: Setting a meaningful minimum bar count prevents the tool from labeling noise.
- **Fib Levels**: Lower-probability retracements can be unchecked unless scalping; keeping 0.618 and 0.786 for reversal zones is the common approach.
- **Display Mode**: A "Clean" mode reduces chart clutter compared to a "Detailed" mode that shows every possible count.

These adjustments are aimed at reducing false signals relative to default behavior.

## How to Use It for Entries and Exits

**Entry Setup**:
1. Wait for a completed wave 2 retracement (ideally to the 0.618 Fib level). The indicator labels this automatically.
2. Enter long on the first bar above wave 2's high with volume confirming.
3. Set the stop loss 1 ATR below wave 2 low.

**Exit Setup**:
1. Take partial profits at the 1.272 extension of wave 1, where wave 3 often stalls.
2. Trail the rest using the 50 EMA or a 5-bar low.

The indicator also applies to corrective waves. When it labels an A-B-C pattern and price reaches the 0.618–0.786 zone of wave A, that is considered a high-probability reversal area.

## Honest Pros and Cons

**Pros**:
- Saves hours of manual Elliott Wave drawing
- Fib levels are accurate and auto-update as waves develop
- Alert system is reliable for wave completions
- Works decently on 1H, 4H, and daily timeframes

**Cons**:
- Fails in ranging markets, where labels become unusable
- Can repaint — the count adjusts as new bars form, so the first label should not be traded
- No multi-timeframe confirmation built-in
- Learning curve for beginners — understanding EW theory is needed to override wrong labels

## Who It's Actually For

- **Intermediate to advanced EW traders** who want to speed up their workflow.
- **Not for beginners** — without a grasp of what a wave 3 extension is, the indicator will confuse more than help.
- **Swing traders** on 4H+ timeframes get the most value. Scalpers on 5M will find the repainting problematic.

## Better Alternatives (If They Exist)

- **Elliott Wave Prophet** — More accurate on lower timeframes but costs $50/month. This one's free.
- **Manual labeling + Fibonacci tool** — More control, but slower. This indicator is preferable for traders working multiple pairs.

## FAQ

**Does it repaint?** Yes. The wave count can shift as new price data comes in. Waiting 2-3 bars after a label appears before acting is prudent.

**Can I use it for crypto?** Yes. It works on BTC and ETH 4H charts. On low-cap altcoins the noise hurts accuracy.

**What's the best timeframe?** 4H for swing trading, 1H for intraday. Daily is fine but signals are rare.

**Does it work in forex?** Better than crypto because forex is less erratic. EUR/USD 1H is a reasonable starting point.

## Final Thoughts

For traders who already understand Elliott Wave theory and just want to automate the labeling, this is a 4/5 tool. The repainting and failings in sideways markets are real drawbacks, but it is free, fast, and accurate enough on trending markets to justify adding to a watchlist.

Don't trust it blindly. Use it as a starting point, then manually confirm.
