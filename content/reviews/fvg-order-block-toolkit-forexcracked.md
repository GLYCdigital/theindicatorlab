The **FVG + Order Block Toolkit [ForexCracked]** is a TradingView indicator built around two concepts that dominate modern price-action trading: fair value gaps (FVGs) and order blocks. If you've spent any time in smart-money or ICT-style circles, both terms will be familiar. This tool's job is to mark them on your chart so you don't have to squint at every candle looking for imbalances and the last opposing candle before a strong move.

As shown in the chart above, the indicator overlays these zones directly on price. That's the entire premise — it's a visual annotation layer, not a signal generator. Worth stating up front, because plenty of traders install something with this name expecting buy/sell arrows and get disappointed.

## What it actually does

Fair value gaps are the price ranges left behind when a market moves so aggressively that one candle's range doesn't overlap with the previous candle's range. The gap between those wicks is the imbalance. Order blocks are the opposing candles — typically the last down candle before a strong up move, or vice versa — that institutions are theorised to have used to build positions.

The toolkit identifies and draws both. That's the core function, and it's the right scope for a tool like this. These concepts are subjective enough that automation is genuinely useful; two traders marking order blocks by hand will rarely agree on every one.

## How to use it

The workflow is straightforward and doesn't depend on undocumented internals:

1. **Add it to a clean chart.** Strip your other indicators first so the zones are readable.
2. **Identify the zones that align with your bias.** A fair value gap below current price in an uptrend is potential support; an order block above price in a downtrend is potential resistance. The tool marks them; you decide which matter.
3. **Use zones as reaction areas, not entries.** Price entering a gap or block is a prompt to watch, not a trigger. Wait for confirmation from your own method.
4. **Combine with structure.** These zones make the most sense when you already know where the swing highs and lows are.

The honest caveat: any automated FVG/order-block marker will produce zones that don't matter. Some gaps get filled instantly, some order blocks never get retested. The indicator can't tell you which is which.
